# ☁️ Introduction and setup

Still as part of my career transition, here are my notes and exercises from **Cocadmin's AWS course** (in French). All credit for the course content, the exercises and the example application goes to Cocadmin: these pages are my personal notes, along with the issues I ran into and how I worked around them. The course introduced me to the AWS ecosystem and its most common services, both through the console and the AWS CLI.

The first step is to set up a working environment to use AWS on my own, before moving on to hands-on infrastructure deployment exercises.

The objectives are as follows:

* Understand the difference between the root account and IAM users, and the related security best practices.
* Install and configure the AWS CLI, and create a dedicated IAM user.
* Host a fast, globally available static website with S3 and CloudFront.
* Deploy and manage EC2 instances inside a VPC.
* Build an auto-scaling, load-balanced infrastructure with ASG and ELB.
* Connect a personal domain name to an AWS infrastructure with Route 53 and ACM.
