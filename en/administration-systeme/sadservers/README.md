# 🛠️ SadServers

[SadServers](https://sadservers.com/) est une plateforme en ligne interactive qui permet de s'entraîner au troubleshooting de serveurs Linux directement depuis le navigateur, sans aucune installation locale.&#x20;

SadServers s'inscrit dans un esprit orientée CTF-Like, comme peut l'être HacktheBox ou TryHackMe par exemple, et permet de tester vos compétences pour l'analyse de logs, des problèmes de connexions, d'espace disque ou de permissions comme le ferait un vrai sysadmin.

Il couvre un large panel de sujets système et infra : Linux, Docker, Kubernetes, bases de données ou monitoring, avec plusieurs niveaux de difficulté. Un chronomètre ajoute une contrainte de temps pour rester proche de la gestion d'un incident de production, et chaque solution rapporte des points.

L'ensemble des sections qui vont suivre sont donc mes Write-Up, mes prises de notes au fil de ces challenges : le raisonnement suivi, les pistes explorées (bonnes comme mauvaises), et les solutions retenues pour chaque cas.

Chaque challenge porte le nom d'une grande métropole dans le monde, d'où le nom de section couvrant les challenges comme "Paris", "Batumi", "Cairo", ou encore "Manhattan".
